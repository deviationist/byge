After the change
The screen a person actually lands on after every mutation, at both breakpoints. The harness renders fixed scenarios, so it cannot show a list mutating — this page is where that behaviour is specified, and it doubles as the design file for the two-pane layout.
Two rules run through all of it. The confirmation lives where the change is visible — a removal is confirmed above the list that is now shorter, not on the screen you were on when you asked. And no notice offers undo, because there is none: the confirmation happened before the deletion, and a dead “Undo” would be worse than no undo at all.
